## Main Page Behaviour

DO NOT ALLOW AUDIENCE TO VIEW THE VIDEO IN FULL SCREEN MODE, AS THEY NEED TO ANSWER QUESTIONS ON THE WEBSITE.

### Video 1

1. Play this video:  
   https://drive.google.com/file/d/1DSN51DVxpZszx41bWc3aV3HKM7CFOq9r/preview
2. Show a button labeled **I've finished watching** below the video so the user can skip it if they want to.
3. When the video finishes, or when the user clicks **I've finished watching**, show [Dora Q&A 1](#dora-qa-1).
4. Ask the user to choose an answer with a **15-second countdown timer**.
5. Add a **click sound** during the countdown.
6. Do **not** show any embedded video while the quiz is being shown.

#### Dora Q&A 1

**Question:** What is one benefit of eating breakfast?

- A. Better focus
- B. More energy
- C. Better appetite control
- D. All of the above

**Correct answer:** D  
**Scoring:** 1 point if correct, 0 if incorrect.
